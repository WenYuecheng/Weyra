# Weyra 0.1.1 修复交付

交付日期：2026-10-20。

本次完成事件订阅恢复、裁判路由通用化、日常命令补齐及 Python 包命名迁移。

## 使用

启动：`weyra`；普通终端：`weyra --ui plain`；模块入口：`python -m weyra.main`。

| 命令 | 行为 |
|---|---|
| `/cost`、`/usage` | 显示人民币费用、调用用量、待结算费用、未知调用与计价可靠性 |
| `/plan on` | 切换到计划权限模式 |
| `/plan off` | 恢复进入计划模式前的权限 |
| `/compact` | 空闲时手动压缩上下文；使用已配置模型及共享费用账本 |
| `/clear` | 清空模型上下文、待处理输入和当前目标，保留历史、持久知识与费用 |

`/clear` 采用同一会话的持久化上下文重置记录，避免清空对话时重置费用。创建独立会话仍使用 `/new`。CLI 与 TUI 使用共享命令及权限实现，忙碌时拒绝修改状态。

## 修复内容

- 事件入队和出队使用相同的 UTF-8 字节计量。订阅溢出会唤醒消费者，TUI 自动恢复持久历史、未完成输出、活动工具与审批，按事件序号过滤重复及旧会话事件。
- 技能裁判从显式 `skill_judge` 路由读取模型，审计保存实际厂商与模型。继续使用原有隔离执行、硬检查、交换顺序评审与发布门禁。
- 手动压缩拥有明确的运行和取消状态；空历史等提前返回路径会结束压缩状态，界面可继续使用。
- 顶级包从 `agents` 迁移到 `weyra`；同步命令入口、资源、当前测试与脚本。历史冻结实验使用兼容加载器读取原包结构，冻结源和原始评分保留。
- 费用未知时显示“未知”，不显示虚假的零金额；终端状态栏支持该返回值。
