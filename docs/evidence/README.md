Polyglot 累计实验包含多个阶段：保留已有 29 题通过结果，再对 35 题继续执行，新增通过 21 题。具体运行与结果口径见[评测说明](../BENCHMARKS.md)。

2026-10-28 的新技能回放实验在三次开发请求上均收到 HTTP 402，随后触发传输停止保护。72 次计划任务中没有完成的效果评测，3 类技能均未更新；不能从该记录报告适应性改善。原始实验账本保守计入约 0.22484 元、8,807 token 预留值，服务未返回实际用量或账单；该摘要保持原样。
