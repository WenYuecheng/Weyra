# Weyra 工程评测

Weyra 的评测围绕两个实际目标组织：在预算约束下持续完成工具任务，以及让技能选择与更新具备可检查的依据。代码修复看实际测试结果，技能定位看同题配对判断，工程回归验证状态、权限与费用边界。

## Polyglot：受预算约束的持续修复

64 道任务覆盖 Python、JavaScript，各 32 题。最终累计 **50/64（78.1%）** 通过，其中 Python **28/32（87.5%）**、JavaScript **22/32（68.8%）**。保留既有通过结果后，对 35 道待修复题继续执行，新增通过 **21/35（60.0%）**。

| 指标 | 结果 |
| --- | ---: |
| 保留的既有通过任务 | 29 |
| 本轮新增通过任务 | 21 |
| 最终累计通过 | 50/64 |
| 累计费率估算 | ¥49.4882 |
| 平均每题费率估算 | 约 ¥0.77 |

这组结果展示了测试反馈与工具闭环对持续修复的价值。运行采用累计协议：既有通过结果与后续修复共同形成最终成绩；曲线 round 0 的 31/64 包含本轮首轮新增通过，不能将其当作独立的无反馈控制组。

### 协议条件

- 主模型端点标识：`DeepSeek-V4.1-Flash`；配置备用模型 `gpt-5.6-luna`。模型标识为所用兼容端点返回的名称。
- 主请求输出上限：**4096 token**；摘要输出 2048，扩展摘要 4096；配置上下文 16384。
- v3 每题限制：80 个模型步骤、120 次物理请求、720 秒；验证超时和重试另见协议摘要。旧阶段的累计消耗计入总报告。
- 验证执行：Python / JavaScript 任务分别运行测试；通过后保留结果，未通过任务继续获得反馈，直到完成或资源耗尽。
- 金额采用产物标记的 `conservative_ceiling_not_provider_invoice`，代表按配置费率的保守估算。
- 官方 [Aider Polyglot](https://aider.chat/docs/leaderboards/) 包含六种语言、225 道题；这里采用两种语言的 64 题子集及独立累计运行协议。

[公开结果摘要](evidence/polyglot-64-summary.json)包含全部 64 个任务的状态；[协议摘要](evidence/polyglot-64-protocol.json)包含任务清单、参数与路由。原始本地产物名称、SHA-256 和脱敏说明见[证据索引](evidence/README.md)。

## 技能定位：同题配对评测

24 个任务各重复两次，共 48 对执行，结果来源为归档 `FINAL-EVIDENCE.json`。

| 指标 | 基线 | Weyra |
| --- | ---: | ---: |
| 技能定位正确 | 26/48（54.2%） | 40/48（83.3%） |
| 配对结果 | — | 14 胜、0 负、34 平 |
| 歧义 / 无匹配场景正确弃权 | 0/8 | 8/8 |

配对提升为 **29.2 个百分点**，报告按 24 个独立任务聚类计算的 bootstrap 95% 区间为 **[12.5%, 50.0%]**。结论对应此组任务及路由策略；它说明技能定位改善，代码任务质量另由实际任务验证。

来源：[定位结果摘要](evidence/skill-localization-summary.json)，公开摘要中的来源产物名称与哈希。

## 工程回归与离线交付

```bash
python -m pytest -q
ruff check .
python -m build
python scripts/verify_package.py
weyra eval --offline --project /tmp/weyra-eval
```

全量测试覆盖模型适配、预算结算、上下文压缩、工具权限、会话恢复、并发取消、技能门禁与终端服务。`verify_package.py` 检查 wheel/sdist 的资源、入口与离线运行；它在临时环境中安装包，并复用当前 Python 环境的依赖。

缓存前缀稳定性、Usage Anchor 与结构化压缩属于可检查的实现机制。具体缓存命中率、首字延迟和事实保留率应随模型、任务与运行记录报告，相关结论与各自的运行记录一起给出。
