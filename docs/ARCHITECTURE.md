# Weyra 架构与执行契约

Weyra 是本地、单用户、单进程的 Python Harness。模型负责生成内容和工具意图，运行时决定接纳、授权、执行和保存。

## 对象与所有权

| 对象 | 职责 |
|---|---|
| Agent | 装配服务、输入队列、完整任务和停止决策；禁止并发重入 |
| ModelRuntime / ProviderRegistry | 全部调用目的的路由、流事件、请求记录与预算 |
| PreparedRequest | JSON 内容快照；嵌套值读取返回副本，模型身份单独保存 |
| ToolRuntime | 所有工具共同校验/权限入口、安全调度、结果检查点 |
| SessionStore | 单写者日志、模型投影、压缩和分支；原始事实不就地修改 |
| ContextManager | 稳定基线、容量估计、低成本缩减及结构化折叠 |
| RunContext | 一次任务的取消、读取版本、资源和事件 |
| Budget | Session 根预留账本；维护有独立额度 |
| ChildManager | 会话拥有子实例；每次委派有独立状态与结果 |
| Jobs / MCPManager | 进程与连接句柄、共享关系及关闭 |
| MemoryStore / SkillStore / EvolutionStore | 事实、方法、维护经验分离 |

## 执行顺序

Session 跨输入存在；Turn 是一次用户任务；Step 是一次模型响应和完整工具批次；Attempt 是一次物理调用。

1. 接纳用户输入，捕获技能目录，按原始输入召回 Memory。
2. 投影原始日志，检查完整工具组和实际模型容量，必要时压缩。
3. 冻结请求、预留预算、保存请求检查点，开始 SDK 流。
4. partial 只用于展示；完整响应接纳后才产生工具副作用。
5. 工具参数校验、当前权限检查、执行意图检查点、执行和定稿。
6. 先持久结果，再发完成通知；模型消息按调用顺序回填。
7. 完整批次后接纳 Steering、子结果和压缩请求。
8. 无工具时检查 Goal；正常结束后执行 Follow-up。取消和额度优先。
9. 关闭任务自有资源，保存终态。会话关闭才回收全部子实例和共享连接。

## 上下文与缓存

System 在会话建立时捕获，动态事实通过追加消息进入。工具声明排序稳定，MCP 只暴露固定桥；厂商切换、压缩、规则刷新或声明变化记录新版本。

`T=floor(min(C×0.8,C−R−H))`，`K=floor((C−R)×0.16)`，`H=min(4096,floor(C×0.05))`。容量包含 System、Schema 和消息。估计使用保守 UTF-8 字节算法；厂商 usage 是记账事实。估计仍可能偏差，因此保留一次独立 overflow 恢复。

轻量缩减和完整折叠都只发布新模型投影。完整折叠保存 episode/working/tool 三层摘要及尾部，原始消息仍在日志。无效、无收益或输入版本变化时不发布。摘要超出辅助窗口时按完整组分段，分段无法安全处理则停止。

客户端不持有服务端 KV；前缀指纹只是组织机制证据。缓存读取可能已包含在厂商输入总量内，适配层负责归一化，不能再次相加。

## 安全与恢复边界

直接、嵌套、子任务和 MCP 调用共用权限入口。父级权限限制会在子任务执行时生效。只读工具允许有限并发，写操作形成屏障；同文件写入检查最近读取内容的哈希。

`fork` 只继承最后已完成用户任务的上下文，当前未完成任务整体排除。角色追加在尾部，子历史不默认回灌。后台完成本身不自动唤醒收费调用。

Session 使用文件锁和检查点。原文、请求和工具结果保留；重复 System/工具声明按内容哈希存储。恢复不执行旧进程，不恢复批准，不重放未知副作用。日志尾部不完整可修复，中间损坏报错。分支是对话历史切换，不是工作区回滚。

Shell 获准后可以执行宿主命令，目录检查不等于 OS 隔离。MCP 必须显式信任才启动，环境不默认继承凭据。Session、工具输出和维护证据可能包含项目资料，应作为本地私有运行数据保存。

## 演化边界

上一轮输出等待下一次用户反馈后进入维护。输入、目标技能正文及哈希在调度时捕获；现有维护调用同时提出修改和经验。经验只用于维护，不作为普通任务指令。

每次最多两处 `replace/append`，每处新增最多 1000 字符；元数据 description/when-to-use 各最多 500 字符。程序提供来源 ID 与基础哈希，模型不能自授写入权限或更换基础版本。先保存来源/旧版，再原子发布；辅助记录失败单独报告，不重复修改。

当前只有静态合法性和恢复约束，不保证每次技能修改提高任务质量。验证发布门禁、训练及完整科研评测不属于 v0.1 自动行为。
