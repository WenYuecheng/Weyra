- 实现用户反馈驱动的 Skills 更新，将经验、知识与技能指令分层保存，以有界文本补丁替代全文改写；旧版与候选在独立临时工作区重执行，经硬断言和次序交换匿名裁判验证，仅在成功数增加且硬失败不增加时发布，支持版本快照、异常恢复与回滚。
- 实现 SQLite WAL 会话树与追加式事件日志，支持会话恢复、分支和派生；结合结构化检查点压缩、模型 Usage 校准、工具长输出剪枝与全文外置，保留继续任务所需状态，并按完整工具交互组处理历史，避免压缩与恢复破坏调用配对。
- 建立请求前预算预留、响应后结算机制，统一约束 Token、调用次数与人民币额度，父子任务共享预算，未知消耗保守记账；结合工具参数校验、路径约束与审批后策略重检治理执行边界，64 题累计费用按配置费率保守估算约 ¥49.49，平均约 ¥0.77/题。
