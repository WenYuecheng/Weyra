# Weyra v0.1 实施追踪

项目按执行契约分阶段交付，全部验证使用临时项目目录和脚本化模型，不加载个人凭据。

- [x] 独立包、命令行入口、独立 Git 仓库与配置格式。
- [x] 规范消息、不可变请求、多厂商流事件、错误与用量归一化。
- [x] 主/辅助/子调用共用运行层，预留与结算，未知用量保守记账。
- [x] JSONL 原始事实、单写者、检查点、分支、恢复和请求输入追溯。
- [x] 稳定 System/声明/历史、指纹、版本、压力缩减、结构化折叠与 overflow。
- [x] 项目 Memory、中文检索、有界模型选择、技能正文和资源版本。
- [x] 工具统一校验/权限、安全并发、独占屏障、有序提交、全文产物。
- [x] stdio MCP 的信任、发现、搜索和真实 Schema 执行。
- [x] 子任务 spawn/fork、后台等待/通信/取消、父级权限和根预算。
- [x] 受管 Shell 作业、等待/取消/交接、进程组清理。
- [x] 双输入队列、Plan、显式 Goal、有界续行及 CLI 命令。
- [x] 来源证据、结构化经验、有界补丁、历史与递增回滚。
- [x] 两套离线可复现演示、二十个固定场景清单及验证说明。
- [ ] 使用用户已有端点完成小额真实多厂商冒烟与缓存对照。
- [ ] 多模型、多种子、完整公开基准与科研消融。

后两项需要真实服务及实验预算，不用脚本化模型结果替代。当前交付优先验证功能和边界，效果指标按实际实验另行报告。
