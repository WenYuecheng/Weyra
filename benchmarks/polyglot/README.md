# Aider Polyglot 五语言配对评测 · 2026-11-24

评测覆盖 **Python、Go、Rust、C++、Java** 五种后端与系统语言。在 168 道最终有效配对题上，**Weyra 两轮累计通过 122 题（72.62%），最小工具循环基线通过 110 题（65.48%），净胜 12 题（+7.14 个百分点）**；逐题胜负为 **Weyra 独赢 31 题、基线独赢 19 题、平局 118 题**，五种语言均取得净胜或持平。

在各自首轮失败后的修复阶段，Weyra 成功修复 **75/123（60.98%）**，高于基线的 **61/121（50.41%）**，领先 **+10.56 个百分点**（其中 C++ 达 **81.0%**、Python 达 **70.8%**、Go 达 **61.5%**）。在 168 组最终有效配对内，Weyra 实际消耗 **1,043,788 tokens**，较基线 **1,208,984 tokens** 节省 **13.66%**。

统计口径：修复率分子为各组首轮失败且第二轮通过的题数，分母为该组已判定的首轮失败题数；首轮和最终配对均仅计入双方同时取得有效判定的题目。该子集 176 题中有 8 题因传输故障缺少最终配对判定，在逐题结果中标记为 `infrastructure_error`。双侧精确 McNemar 检验 `p = 0.119`。

## 协议与离线复算

两组使用相同的 **GLM-5.3-Flash** 模型、`high` 推理强度、8,192 输出 token 上限与 `write_file` 工具，每次提交最多发起 1 次模型请求，最多 2 次正式提交，并共享相同题面、无网络 Docker 验收镜像和有界测试反馈。Weyra 首轮注入样例、边界与接口核对提示，次轮用题面、当前实现、改动文件的原始模板和最新测试诊断重建精简上下文；基线在次轮延续原会话历史。

- [results.csv](results.csv)：五种语言共 176 道题的任务 ID 与两组各阶段判定（空字段表示该阶段未产生判定，`infrastructure_error` 表示传输故障导致最终判定缺失）。
- [protocol.json](protocol.json)：记录数据集与运行时代码版本、模型参数、Docker 镜像摘要、分段并发与冻结记录的 SHA-256。
- [policy.py](policy.py)：本轮实际采用的提示构造源码。
- [report.py](report.py)：基于逐题判定离线重算配对通过数、修复率、胜负对及精确配对检验。

```bash
python benchmarks/polyglot/report.py
```

复算仅依赖 Python 3.11+。题目来源与原始模板见 [Aider Polyglot Benchmark](https://github.com/Aider-AI/polyglot-benchmark/tree/7e0611e77b54e2dea774cdc0aa00cf9f7ed6144f)。
