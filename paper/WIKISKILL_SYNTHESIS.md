# WikiSkill 方法映射：把经验积累接入技能维护

[WikiSkill（arXiv:2608.27454v1，2026）](https://arxiv.org/abs/2608.27454v1) 将原始执行经验、持久知识和可执行技能分开组织，通过持续积累知识支持后续技能演进。

Weyra 采用这一思路，将用户纠偏中的适用边界与执行方法分开处理。适用边界进入知识记录；需要改变执行流程的建议进入候选技能维护，避免一次具体任务的细节直接覆盖通用方法。

| 环节 | 主要实现 | 工程作用 |
| --- | --- | --- |
| 确认更新目标 | `skills.py` 的技能定位与使用快照 | 将反馈归因到实际使用的技能 |
| 提炼反馈 | `online_skill_evolution.py` | 产生结构化维护建议 |
| 积累知识 | `skill_evolution.py` | 保存经验边界、来源和注入配额 |
| 修改技能 | 有界补丁与验证门禁 | 保持更新范围可检查 |
| 保存决策 | 演进记录与版本快照 | 支持追踪、拒绝原因检查与回滚 |

项目中的长度、条数和注入配额属于具体工程配置；引用论文的方法思想与本项目的参数选择分别说明。技能定位的同题配对结果见[工程评测](../docs/BENCHMARKS.md)。
